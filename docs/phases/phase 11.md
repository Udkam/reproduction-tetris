  including one Mutation attachment and one Puzzle preview.
- **Survival:** countdown shelf, settled shelf, one-stone event, two-stone connected
  event, ordinary pieces above geology, desktop and portrait.
- **Mutation:** Ice start/middle/end; Supergravity active, projected independent ghost,
  and settlement; Bomb activation without a rectangular target; simultaneous items;
  reduced motion.
- **HUD and Settings:** Classic, Survival, Mutation, and Puzzle rails; all four Settings
  sections; Chinese/English at `1440×900`, `390×844`, and `844×390`.
- **Home:** pointer hover/leave on all four cards and keyboard focus with full borders.
- **Puzzle:** at least one direct-clear state, one hole-risk state, and one setup state;
  metrics change only at deterministic decisions and survive undo/restart correctly.
- Every capture proves one gameplay Canvas, zero DOM board cells, zero unintended
  overflow, and zero console/page errors.

## Resource boundary

- One production writer. Independent QA is read-only after an immutable candidate.
- No Serena, WMI/CIM, persistent indexer, language server, watcher, or inspection-only
  browser. Focused tests use one worker and no file parallelism.
- Only the final visual stage may own one Vite server and one managed browser batch;
  record command, parent, start time, purpose, and port, then release both.
- Full suite/build run once after the last source edit, not after every checkpoint.
