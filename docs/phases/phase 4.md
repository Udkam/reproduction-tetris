# Phase 4：Survival 压力系统

## 状态

**已开放。** Phase 3 验收恢复记录
`1383fca794cba150d373597a21d6686a02922b02` 已推送；Phase 4 以该提交为
回退基线。产品源码尚未开始修改。

## 目标

把上升基岩与独立落石整理为一个可预测、可读且公平的压力系统。玩家应能判断
下一次威胁何时发生、来自哪里，并理解落石既可能阻碍也可能协助消行。

## 冻结规则

- 开局三层棕色基岩；不再尝试石头纹理或不规则轮廓。
- 基岩周期从 13 秒逐步缩短到 6 秒；每消 3 行移除一层。
- 独立落石周期从 20 秒逐次减 1 到 10 秒；每次 1–2 枚。
- 落石速度约为普通方块下落速度的 1.5 倍，独立更新，可参与消行和得分。
- 生存普通方块保持既定固定速度；随机七袋与落石随机源必须隔离且可重放。
- 排行只记录/显示生存时间、消行数和日期，不显示方块数。

## 实现阶段

1. `survival-core`：计时、独立落石、消行、RNG 隔离与确定性测试。
2. `survival-render`：棕色基岩、落石运动、生成前公平预警和 reduced-motion 端点。
3. `survival-ui`：压力/落石双时钟与紧急状态，不增加长说明。
4. `candidate/evidence`：长时运行、边界消行、顶出、重启/卸载资源验证。

每个检查点独立提交，不把 Core、Renderer 和 UI 压成一个无法回退的 commit。

## 协作团队

- writers：`t15_survival_core_writer` → `t15_survival_render_writer` →
  `t15_survival_ui_writer`，严格顺序交接。
- 规则/确定性 QA：`t15_survival_rules_qa`。
- 视觉/公平性 QA：`t15_survival_visual_qa`。
- 必要时由证据 QA 核对长时计时和 RNG replay。

## 验收

验证 13→6、20→10、1–2 落石、1.5×速度、每三行降基岩、落石触发行消除、
重启重放一致、排行字段正确；桌面/紧凑屏幕清楚显示威胁，无帧卡顿、泄漏、
第二 Canvas 或 DOM 方格。
