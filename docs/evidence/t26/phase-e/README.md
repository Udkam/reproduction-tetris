return-home sequence:

- restart preserves exactly one Canvas, two renderer animation frames, the
  active listener set, one live AudioContext, and a visible Next preview;
- return home restores zero Canvas, zero renderer animation frames, four
  baseline window/document listeners, and no QA bridge;
- the one AudioContext created by the run is closed exactly once;
- the Vite development baseline interval remains one throughout;
- no browser error or DOM board cell is recorded.

`restart-next-visible.png`, `pause-next-visible.png`, and
`home-after-runtime-release.png` are the inspected source-bound frames. They
show the live Next well through restart and pause, the persistent Back and
Settings actions, and the clean Home surface after runtime release.

## Delivery inspection

- Explicit WOFF2 delivery reduced the emitted font payload from `11,208,240`
  to `4,752,492` bytes: `6,455,748` bytes / `57.6%` removed. The final build
  emits 13 WOFF2 files and zero legacy WOFF files.
- The production output totals `5,924,134` bytes for this candidate.
- A one-shot scoped OSV Scanner 2.4.0 scan of `package-lock.json` reports no
  known dependency issue. `npm ls --depth=0` reports the expected dependency
  tree without an extraneous or missing package.
- A one-shot source-map composition audit attributes the retained main chunk
  primarily to React DOM, the Pixi renderer, application composition, Core,
  PixiJS, and authored Puzzle data. The `546.62 kB` minified / `159.74 kB`
  gzip warning is deliberately visible: threshold suppression or static
  chunk reshuffling would not reduce first-run execution weight, while a new
  lazy runtime boundary would add release risk to the accepted game.
- Unused legacy font binaries and their obsolete notice entries were removed
  only after active-source and build-output inspection.

## Reproduction

From a clean clone, install the committed dependencies and the pinned Chromium
runtime once, then run the bounded owner script:

```powershell
npm.cmd ci
npx.cmd playwright install chromium
node docs/evidence/t26/phase-e/run-phase-e-evidence.mjs
```

The repository-declared Playwright dependency is used directly. The runner closes its
single server and browser in `finally`, so it leaves no persistent helper or listener.
